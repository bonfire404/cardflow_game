OVERVIEW
--------
CardFlow is a digital implementation of the traditional Filipino card game
Tong-its, produced by BONFIRE BASE Studio.

This frontend package contains the presentation layer of the game, including
the game logic, user interface, and supporting modules.


================================================================================

WHAT IS INCLUDED
----------------
The following folders and files are included in this frontend package:

  assets/
    Casino/Cards/          Playing card sprites (52 cards + card back)
    Casino/Chips/          Chip sprites for the betting system
    fonts/                 Custom typography (Inter, Sora, JetBrains Mono, Sekuya)
    game_icons/            UI icons (PNG, Spritesheet, Vector formats)
    images/                Logos, avatars, lobby backgrounds, rank badges, tables
    music/                 Background music tracks
    sfx/                   Sound effects (card flip, win, deal, etc.)
    splashscreen.gif       Animated splash screen
    ingame_screenshot/     screenshots of the game

  python_prototype/
    game/                  Core game logic (engine, AI, economy, models)
    ui/                    User interface rendering and event handling
    db/                    Local save data (encrypted — see Backend README)

  README(frontend).txt     This file
  README(backend).txt      Backend documentation and technical details
